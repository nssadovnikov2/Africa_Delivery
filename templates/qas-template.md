# Quality Attribute Scenario — template

| Field | Meaning |
|---|---|
| Source | Who/what generates the stimulus |
| Stimulus | The event that arrives |
| Artifact | Part of the system that is stimulated |
| Environment | Conditions (normal, peak, degraded, region outage) |
| Response | What the system does |
| Response measure | How the response is measured — the testable target |
